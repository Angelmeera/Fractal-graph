# Fractal-graph and Graceful Labeling
This repository contains Jupyter notebooks that explore fractal constructions and graph labeling problems, with a focus on **Iterated Function Systems (IFS)** and **graceful labeling techniques**.

### 1. `Graceful_labeling_of_Viscek_fractal.ipynb`
- Constructs the **Vicsek fractal graph** using recursive subdivision.  
- Applies **graceful and odd graceful labeling** techniques.  
- Explores how graph labeling can enhance applications in **communication networks**, such as frequency assignment and channel allocation.

### 2. `Heighway_Dragon.ipynb`
- Implements the **Heighway Dragon curve** using **L-systems**.  
- Demonstrates fractal generation iteratively.  
- Includes visualizations and graph representations of the dragon curve.  
- Discusses possibilities of applying **graceful labeling** to fractal-based graphs.

### 3. `Viscek_Fractal.ipynb`
- Focuses on the **construction of the Vicsek fractal** using IFS.  
- Provides mathematical formulation and visualizations.  
- Serves as the foundation for further labeling experiments.
